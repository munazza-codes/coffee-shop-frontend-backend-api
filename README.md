# Coffee Shop

A responsive Coffee Shop website built with HTML, CSS, JavaScript, Node.js, and Express.js.
The project includes a modern coffee menu and a backend API for serving menu data.

## Features

* PC/Mobile both Responsive Coffee Shop website
* Home, About, Menu, Reviews, and Contact pages
* Coffee menu with images and prices
* Backend API using Node.js and Express.js
* Frontend connected to backend API
* Clean and simple user interface
